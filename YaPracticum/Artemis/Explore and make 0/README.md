# Alpha-Soft Task Tracker

Простой учебный backend-проект на Django REST Framework.

Проект сделан по заданию для компании "Альфа-Софт". Нужно было реализовать небольшой таск-трекер, где есть пользователи, проекты, задачи, комментарии, фильтрация, пагинация и документация API.

## Что реализовано

- регистрация пользователя;
- получение токена;
- создание проектов;
- добавление и удаление участников проекта;
- создание, просмотр, изменение и удаление задач;
- комментарии к задачам;
- фильтрация задач;
- пагинация;
- Swagger и ReDoc.

## Сущности

### Project

- название;
- описание;
- владелец;
- участники;
- дата создания.

### Task

- проект;
- заголовок;
- описание;
- автор;
- исполнитель;
- статус;
- приоритет;
- дедлайн;
- дата создания;
- дата обновления.

### Comment

- задача;
- автор;
- текст;
- дата создания.

## Права доступа

- пользователь видит только свои проекты;
- пользователь видит только задачи и комментарии из своих проектов;
- владелец проекта может редактировать проект и управлять участниками;
- владелец проекта может менять и удалять любые задачи проекта;
- автор задачи может менять описание и удалять свою задачу;
- исполнитель задачи может менять статус и приоритет;
- комментарий может создать любой участник проекта;
- комментарий может удалить автор комментария или владелец проекта.

## Установка и запуск

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Выполнить миграции:

```bash
python manage.py migrate
```

3. Создать суперпользователя:

```bash
python manage.py createsuperuser
```

4. Запустить сервер:

```bash
python manage.py runserver
```

## Авторизация

Для работы с API используется Token Authentication.

Сначала нужно зарегистрироваться через `/api/register/` или создать пользователя через админку. Потом отправить `username` и `password` на `/api/token/` и получить токен.

Токен передается в заголовке:

```text
Authorization: Token ваш_токен
```

## Основные эндпоинты

- `POST /api/register/` - регистрация
- `POST /api/token/` - получение токена
- `GET /api/projects/` - список проектов текущего пользователя
- `POST /api/projects/` - создать проект
- `GET /api/projects/{id}/` - получить проект
- `PATCH /api/projects/{id}/` - изменить проект
- `DELETE /api/projects/{id}/` - удалить проект
- `POST /api/projects/{id}/add_member/` - добавить участника
- `POST /api/projects/{id}/remove_member/` - удалить участника
- `GET /api/tasks/` - список задач
- `POST /api/tasks/` - создать задачу
- `GET /api/tasks/{id}/` - получить задачу
- `PATCH /api/tasks/{id}/` - изменить задачу
- `DELETE /api/tasks/{id}/` - удалить задачу
- `GET /api/comments/` - список комментариев
- `POST /api/comments/` - создать комментарий

## Фильтрация задач

Поддерживаются фильтры:

- `project`
- `status`
- `priority`
- `assignee`
- `deadline`
- `deadline_before`
- `deadline_after`

Пример:

```text
/api/tasks/?status=todo&priority=high
```

## Документация API

- Swagger: `http://127.0.0.1:8000/api/schema/swagger/`
- ReDoc: `http://127.0.0.1:8000/api/schema/redoc/`
- Schema: `http://127.0.0.1:8000/api/schema/`
